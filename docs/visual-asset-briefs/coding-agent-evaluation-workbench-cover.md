# Visual asset brief: Coding Agent Evaluation Workbench cover

## Status

Owner-generated asset required. No cover image was supplied with Stage 7A.1, so the published project keeps its text-first cover treatment.

## Proposed asset

- Project: Coding Agent Evaluation Workbench
- Purpose: Editorial cover for the catalog card and, if approved, the opening visual of the project detail page.
- Recommended path: `assets/images/coding-agent-evaluation-workbench-1600x1000.webp`
- Recommended dimensions: 1600 × 1000 px, 8:5 landscape, with the primary subject kept inside the central 70% safe area for mobile cropping.
- Intended placement: Catalog cover first; optional detail-page opener above the project overview after owner approval.

## Confirmed visual concept

A restrained editorial composition showing a standardized reference codebase as a neutral rectangular specimen, a versioned task brief entering from the left, a sequence of run evidence cards through the center, and separate validation/review markers on the right. The visual should communicate reproducibility, traceability, and evaluation boundaries rather than autonomous software development.

Confirmed elements may include: versioned task specification, clean baseline, coding-agent execution, run artifacts, deterministic functional and code-quality checks, security/authorization review, structured human assessment, advisory assessment where applicable, and comparative reporting.

## Style direction

Premium Technical Editorial: charcoal `#11161B`, warm ivory `#ECE5D7`, khaki `#B8A58C`, coffee `#785C4B`, muted blue `#7FA7B4`, and restrained terracotta `#D67B56`. Use Swiss/Bauhaus-inspired geometry, generous negative space, disciplined typography, and a small number of labeled shapes. Preserve the existing portfolio shell and avoid global palette changes.

## English image-generation prompt

```text
Create a premium technical editorial illustration for an internal Coding Agent Evaluation Workbench case study. Show a standardized full-stack reference codebase as a neutral rectangular specimen, a versioned task specification entering from the left, a controlled clean baseline, a central coding-agent execution stage, a compact evidence bundle containing diffs, logs, transcripts, and test results, and a separated validation/review area containing deterministic checks and human or advisory assessment. Convey reproducibility, traceability, and comparative engineering evaluation through Swiss graphic design, refined Bauhaus geometry, disciplined grid alignment, generous negative space, and restrained information-design labels. Use a charcoal background, warm ivory typography, khaki and coffee neutrals, muted blue connectors, and restrained terracotta accents. Landscape 8:5 composition, central safe area for mobile cropping, crisp print-editorial finish, no gradients, no glossy UI.
```

## Explicit exclusions

Do not show benchmark scores, leaderboard rankings, validation-check counts, model names, customer information, repository names, confidential code, private experiment artifacts, fake dashboards, chat transcripts with readable private content, floating robots, holographic interfaces, neural-network decoration, or imagery implying fully autonomous evaluation.
